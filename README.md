# OpusByte - Technology Solutions, Cloud & AI Innovation

OpusByte is a technology solutions company dedicated to helping businesses transform ideas into impactful digital products and intelligent business solutions. We combine software engineering excellence, cloud technologies, and artificial intelligence to deliver innovative solutions that drive growth, efficiency, and long-term success.

## 🚀 Quick Start

Ensure you have Node.js (v18+) installed.

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

The dev server will run on `http://localhost:3000`.
